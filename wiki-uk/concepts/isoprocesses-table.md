# Процеси в ідеальному газі: одна таблиця

Теми: [01 закони](../topics/molecular/01_Закони_ідеальних_газів.md), [07–09](../topics/molecular/07-09_Ізопроцеси.md), [10](../topics/molecular/10_Адіабатний_процес.md), [05 C](../topics/molecular/05_Теплоємність_ідеальних_газів.md)

ν = m/M молів. Перший закон: Q = ΔU + A. Для ідеального газу завжди **ΔU = νC_VΔT**. Джерела: т. 1, § 14.7, § 16.3–16.4.

| процес | умова | рівняння | закон | A (газу) | ΔU | Q | C | n (pVⁿ) |
|---|---|---|---|---|---|---|---|---|
| ізохорний | V = const | p/T = const | (14.28) | 0 | νC_VΔT | = ΔU | C_V | ±∞ |
| ізобарний | p = const | V/T = const | Гей-Люссака | p(V₂−V₁) = νRΔT | νC_VΔT | νC_pΔT | C_p = C_V + R | 0 |
| ізотермічний | T = const | pV = const | Бойля–Маріотта | νRT ln(V₂/V₁) | 0 | = A | ∞ | 1 |
| адіабатний | d'Q = 0 | pV^γ = const, TV^(γ−1) = const | Пуассона | νC_V(T₁−T₂) | −A | 0 | 0 | γ |
| політропний | C = const | pVⁿ = const | (16.40) | — | νC_VΔT | νCΔT | C | (C_p−C)/(C_V−C) |

✏️ Одна діаграма p–V зі спільної точки з усіма чотирма кривими: ізохора (вертикаль), ізобара (горизонталь), ізотерма (гіпербола) й адіабата (крутіша гіпербола).

Значення: одноатомний газ γ = 5/3, двохатомний 7/5, багатоатомний 4/3 (див. [05](../topics/molecular/05_Теплоємність_ідеальних_газів.md)).
