# Позначення, знаки й одиниці

Довідка для читання інших джерел поряд із Кучеруком: слайдів лекцій, англомовних підручників, задачників, авіаційно-космічної літератури. Та сама фізика може виглядати інакше, бо відрізняються літери, знаки чи одиниці. Стовпець книги звірено зі сканами; «інші тексти» — поширене сучасне або англомовне вживання.

## Книга vs інші тексти

| величина | Кучерук | інші тексти |
|---|---|---|
| неповний диференціал | d′Q, d′A | δQ, δW, đQ |
| скалярний добуток | $\vec p\vec E$ (без крапки) | $\vec p\cdot\vec E$ |
| векторний добуток | $[\vec p\cdot\vec E]$, (1.25) | $\vec p\times\vec E$ |
| ротор, дивергенція | rot, div | ∇ ×, ∇ ·; англ. curl |
| середнє | ⟨v⟩ | $\bar v$ |
| найбільш імовірна / середня квадратична швидкість | $v_н$ / $v_{кв}$ | $v_p$ / $v_{rms}$ |
| число молекул / концентрація | n / n₀ | N / n |
| молярна маса | M | M, μ (старіші тексти) |
| ентальпія / потенціал Гіббса / вільна енергія | I / Z / F | H / G / F або A |
| гравітаційна стала | γ | G |
| теплопровідність | λ | k, κ |
| тепловий потік | $j_q$ | q, $\vec q$ |
| характеристичні температури | $T_{оберт}$, $T_{кол}$ | θ_rot, θ_vib |
| об'ємноцентрована гратка | J | I |
| холодильний коефіцієнт / коефіцієнт перетворення | ε / φ | COP_R / COP_HP |
| ЕРС | ℰ | ℰ, англ. emf |

## Знаки

| що | Кучерук | інше |
|---|---|---|
| робота в першому законі | A — робота **системи**: $d'Q = dU + d'A$ (16.11) | хімія, IUPAC: W — робота **над** системою, ΔU = Q + W |
| теплота | надана системі > 0 (с. 380) | так само майже скрізь |
| Q₂ у циклі | у η = 1 − Q₂/Q₁ модуль; у (16.71) зі знаком, Q₂ < 0 | багато текстів скрізь пишуть $Q_C$ або $\lvert Q_2\rvert$ |
| дипольний момент | від − до + (1.19) | у деяких хімічних текстах стрілка від + до − |
| напрям струму | рух **позитивних** зарядів (т. 2, с. 106) | так само; електрони рухаються навпаки |
| нормаль у потоці | зовнішня — додатна (с. 36) | так само |
| ЕРС у правилі Кірхгофа | > 0, якщо обхід проходить джерело від − до + | та сама домовленість, але перевіряйте в кожному тексті |

## Як не заплутатися
- Переписуючи формулу з іншого джерела, спершу перевірте три речі: що означає кожна літера, знак роботи і чи формула записана на моль, на кілограм чи для всього тіла ($C$, $c$, $C_0$ у (16.7)–(16.9)).
- Книга пише десяткові дроби з комою (8,31); англомовні тексти — з крапкою (8.31).
- У рукописних конспектах оберіть один символ для кожної величини, а якщо відступаєте від книги — напишіть угорі сторінки короткий список позначень.
