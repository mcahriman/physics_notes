# 4. Потенціал електричного поля — каркас

📖 т. 2, **§ 1.10** (с. 44–45, робота), **§ 1.11** (с. 48–56). ✅ Формули звірено зі сканом.

## План сторінки
```
┌ [A] Робота поля не залежить від шляху (1.44)–(1.46) ┐
├ [B] Означення φ (1.54)  │ [C] φ точкового заряду (1.55)  ┤
├ [D] Суперпозиція (1.56) │ [E] Різниця потенціалів, напруга (1.59), еВ ┤
└ [F] Еквіпотенціальні поверхні: рис., E ⟂ поверхні     ┘
```

## [A] Робота сил поля (с. 44–45)
- Переміщення q₀ у полі заряду q з точки 1 у точку 2: $A_{12} = \dfrac{qq_0}{4\pi\varepsilon_0}\left(\dfrac1{r_1}-\dfrac1{r_2}\right)$ (1.45)
- Робота **не залежить від форми шляху**, отже поле **потенціальне (консервативне)** (англ. conservative field).
- По замкненому контуру робота дорівнює 0: $\oint_L \vec E\,d\vec l = 0$ (1.46) — **циркуляція вектора E** (англ. circulation). Докладніше — у [темі 9](09_Теорема_Стокса.md).

## [B] Означення потенціалу (с. 48–49)
- $A_{12} = W_1 - W_2$: робота дорівнює **зменшенню** потенціальної енергії (1.53).
- $\varphi_1 = \dfrac{A_{1\infty}}{q_0} = \int_1^\infty E\,dl\cos\alpha$ (1.54)
- Означення книги: «фізична величина, що чисельно дорівнює роботі, яку виконують сили електричного поля при переміщенні **пробного одиничного заряду** із заданої точки **в нескінченність**» (англ. electric potential)
- Рівнозначне означення: **відношення потенціальної енергії заряду до значення цього заряду**, $\varphi = W/q_0$.
- φ — **скалярна** (англ. scalar) величина й **енергетична характеристика** поля (англ. energy characteristic). 1 В = 1 Дж/1 Кл.
- Нуль відліку: φ(∞) = 0 у теорії, φ(Землі) = 0 на практиці.

## [C] Потенціал точкового заряду (с. 50)
- $\varphi = \dfrac{1}{4\pi\varepsilon_0}\dfrac{q}{r}$ (1.55); додатний для +q, від'ємний для −q.

## [D] Суперпозиція (с. 50)
- $\varphi = \dfrac{1}{4\pi\varepsilon_0}\sum_i \dfrac{q_i}{r_i}$ (1.56) — **алгебрична**, а не векторна сума. У цьому головна практична перевага φ над E.
- Неперервний розподіл: $\varphi = \dfrac{1}{4\pi\varepsilon_0}\int \dfrac{\rho\,dV}{r}$ (1.57).

## [E] Різниця потенціалів = напруга (с. 50–51)
- φ визначений лише з точністю до адитивної сталої, тож фізичний зміст має **Δφ**:
  $\varphi_1 - \varphi_2 = \dfrac{A_{12}}{q_0}$ (1.59), позначають **U** (англ. voltage), одиниця — вольт.
- **Електрон-вольт**: 1 еВ = 1,6·10⁻¹⁹ Дж.

## [F] Еквіпотенціальні поверхні (с. 51)
- Поверхня, на якій φ = const (англ. equipotential surface). Переміщення заряду вздовж неї не потребує роботи, отже **E ⟂ поверхні**.
- Поверхня провідника еквіпотенціальна.
- ✏️ Малюнок: точковий заряд, концентричні кола (φ) і радіальні стрілки (E).
