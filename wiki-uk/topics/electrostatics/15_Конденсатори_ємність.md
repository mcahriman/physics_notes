# 15. Конденсатори та їх ємність. Ємність плоского, циліндричного та сферичного конденсаторів — каркас

📖 т. 2, **§ 1.14** (с. 60–63). ✅ Формули звірено зі сканом.

## План сторінки
```
┌ [A] Ємність відокремленого провідника (1.68); фарад; куля C = 4πε₀εR ┐
├ [B] Конденсатор: означення, обкладки, (1.70); вплив діелектрика ε     ┤
├ [C] Плоский │ [D] Циліндричний │ [E] Сферичний  (три малюнки в ряд)  ┤
└ низ: робоча напруга / пробій                                           ┘
```

## [A] Електрична ємність провідника (с. 60)
- Для відокремленого провідника q/φ = const: $C = \dfrac{q}{\varphi}$ (1.68), $\Delta q = C\Delta\varphi$ (1.69) (англ. capacitance)
- Зміст: «електрична ємність провідника чисельно дорівнює зарядові, який потрібний для зміни потенціалу провідника на одиницю»
- Одиниця — **фарад**, 1 Ф = 1 Кл/В. Це дуже велика одиниця: ємність 1 Ф мала б куля радіуса R = 9·10⁶ км. Тому вживають мкФ = 10⁻⁶ Ф і пФ = 10⁻¹² Ф.
- Куля: $C = 4\pi\varepsilon_0\varepsilon R$.
- C залежить від **розмірів, форми та навколишнього середовища**, але не від матеріалу чи порожнин усередині.

## [B] Конденсатор (с. 61)
- «система з двох металевих електродів, розміщених на близькій відстані один від одного і розділених шаром діелектрика» (англ. capacitor); електроди називають **обкладками** (англ. plates).
- Поле зосереджене майже повністю між обкладками, тож C майже не залежить від сусідніх тіл (на відміну від відокремленого провідника).
- $C = \dfrac{q}{\varphi_1-\varphi_2} = \dfrac{q}{U}$ (1.70)
- Із діелектриком: $C/C_0 = \varepsilon$.

## [C] Плоский (с. 61)
- Дві паралельні пластини площею S на відстані d ≪ розмірів пластин (крайовими ефектами нехтуємо).
- У вакуумі: $\varphi_1-\varphi_2 = Ed = \dfrac{\sigma}{\varepsilon_0}d = \dfrac{q}{\varepsilon_0S}d$ ([тема 11](10-12_Поля_площини_двох_площин_сфери.md)) ⟹ $C = \dfrac{\varepsilon_0S}{d}$ (1); з діелектриком $C = \dfrac{\varepsilon_0\varepsilon S}{d}$

## [D] Циліндричний (с. 61–62)
- Два коаксіальні циліндри r₁ < r₂ висотою h ≫ r.
- У вакуумі: $E = \dfrac{\eta}{2\pi\varepsilon_0 r}$ ⟹ $\varphi_1-\varphi_2 = \dfrac{\eta}{2\pi\varepsilon_0}\ln\dfrac{r_2}{r_1}$ ⟹ $C = \dfrac{2\pi\varepsilon_0h}{\ln(r_2/r_1)}$ (2); з діелектриком $C = \dfrac{2\pi\varepsilon_0\varepsilon h}{\ln(r_2/r_1)}$. η — лінійна густина заряду.
- Малий зазор d = r₂ − r₁ ≪ r₁ дає $C\approx\dfrac{2\pi\varepsilon_0\varepsilon r_1h}{d}$ — плоский конденсатор. ✏️ Варто записати, чому.

## [E] Сферичний (с. 62)
- Дві концентричні сфери r₁ < r₂.
- У вакуумі: $\varphi_1-\varphi_2 = \dfrac{q}{4\pi\varepsilon_0}\left(\dfrac1{r_1}-\dfrac1{r_2}\right)$ ⟹ $C = \dfrac{4\pi\varepsilon_0r_1r_2}{r_2-r_1}$ (3); з діелектриком $C = \dfrac{4\pi\varepsilon_0\varepsilon r_1r_2}{r_2-r_1}$

## Та сама схема тричі (наш підсумок)
Знайти E (Гаусс) → проінтегрувати й отримати U → C = q/U. ✏️ Запишіть цей рядок над трьома малюнками.

## Низ (с. 63)
- **Робоча напруга** (англ. rated voltage) U_p: вище неї настає **пробій** (англ. breakdown).
- Необов'язково: двопровідна лінія, $C \approx \pi\varepsilon_0h/\ln(d/r)$ для довжини h, d ≫ r (приклад 1.3, (4)).

## Доповнення (не з книги)
