# 16. З'єднання конденсаторів — каркас

📖 т. 2, **§ 1.14** (с. 63–64). ✅ Формули звірено зі сканом. Коротка тема: пів сторінки.

## План сторінки (дві колонки)
```
┌ Паралельне (рис. 1.31)        │ Послідовне (рис. 1.32)          ┐
│ U однакова                    │ q однаковий (електростатична індукція) │
│ q = q₁ + q₂ + …               │ U = U₁ + U₂ + …                  │
│ C = C₁ + C₂ + … (1.71)        │ 1/C = 1/C₁ + 1/C₂ + … (1.72)     │
│ n однакових: C = nC₀          │ n однакових: C = C₀/n            │
└ низ: навіщо (батареї); імпульс nU (рис. 1.33)                    ┘
```

## Паралельне з'єднання (с. 63)
- На всіх конденсаторах однакова напруга U, заряди додаються: $q = (C_1+C_2+\ldots+C_n)U$ (англ. parallel connection).
- $C = C_1 + C_2 + \ldots + C_n$ (1.71)

## Послідовне з'єднання (с. 63–64)
- Завдяки **електростатичній індукції** заряд q на всіх конденсаторах однаковий, напруги додаються (англ. series connection).
- $\dfrac1C = \dfrac1{C_1}+\dfrac1{C_2}+\ldots+\dfrac1{C_n}$ (1.72)
- C завжди **менша за найменшу** Cᵢ.

## Навіщо з'єднувати (с. 63)
- Щоб отримати потрібну ємність при потрібній напрузі — **батарея конденсаторів** (англ. capacitor bank). Послідовне з'єднання ділить напругу, тож батарея витримує більшу.
- Прийом (с. 64, рис. 1.33): заряджають n конденсаторів паралельно до U, потім перемикають послідовно й отримують nU. Так одержують імпульси високої напруги.

## ✏️ Ваш рядок
- Порівняйте з резисторами ([тема 22](22_Правила_Кірхгофа.md)): ємності **додаються при паралельному**, а опори — **при послідовному** з'єднанні. Запишіть чому: C ∝ q/U, а R ∝ U/I.
