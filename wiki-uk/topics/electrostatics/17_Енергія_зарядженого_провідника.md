# 17. Енергія зарядженого провідника — каркас

📖 т. 2, **§ 1.25** «Енергія взаємодії електричних зарядів» (с. 101–103), початок **§ 1.26** (с. 103–104). ✅ Формули звірено зі сканом.

## План сторінки
```
┌ [A] Енергія двох зарядів (1.128)–(1.129) ┐
├ [B] Система n зарядів (1.130): чому ½    ┤
├ [C] Заряджання провідника: dA = φ dq → (1.132) ┤
└ [D] Те саме для конденсатора (1.133)       ┘
```

## [A] Два точкові заряди (с. 101–102)
- Зближуємо заряди з нескінченності: $W = \dfrac{1}{4\pi\varepsilon_0}\dfrac{q_1q_2}{r_{12}}$ (1.128) (англ. interaction energy)
- У симетричній формі: $W = \tfrac12(q_1\varphi_1 + q_2\varphi_2)$ (1.129), де φ₁ — потенціал, який створює q₂ у точці q₁.

## [B] Система n зарядів (с. 102)
- $W = \dfrac12\sum_{i=1}^n q_i\varphi_i$ (1.130), де φᵢ — потенціал у точці qᵢ від **усіх інших** зарядів.
- **Чому ½**: кожна пара входить у суму двічі.
- Неперервний розподіл: $W = \tfrac12\left(\int\rho\varphi\,dV + \int\sigma\varphi\,dS\right)$.

## [C] Енергія зарядженого провідника (с. 103–104)
- Заряджаємо провідник порціями dq з нескінченності. Кожна потребує роботи $dA = \varphi\,dq = \dfrac{q}{C}dq$.
- Від 0 до q: $A = \dfrac{q^2}{2C}$ — вона й стає запасеною енергією.
- $W = \dfrac{q\varphi}{2} = \dfrac{C\varphi^2}{2} = \dfrac{q^2}{2C}$ (1.132)
- ✏️ Намалюйте графік: φ від q — пряма через 0, а **W — площа під нею**, трикутник. Звідси й ½.

## [D] Конденсатор (с. 104)
- Та сама формула, де φ замінено на U: $W = \dfrac{CU^2}{2} = \dfrac{qU}{2} = \dfrac{q^2}{2C}$ (1.133)
- Наочно: заряд переносять з однієї обкладки на іншу.
