# 21. Поняття опору. Потужність — каркас

📖 т. 2, **§ 2.2** (с. 111–114), **§ 2.4** (с. 121–123). ✅ Формули звірено зі сканом.

## План сторінки
```
┌ [A] Опір R: означення, Ом, звідки береться        ┐
├ [B] R = ρl/S (2.18); питомий опір; σ = 1/ρ (2.21) ┤
├ [C] Залежність від T (2.19)–(2.20) + графік ρ(T)  ┤
├ [D] Робота струму (2.38)–(2.41)                   ┤
└ [E] Потужність (2.43)–(2.46); ККД; макс. при R = r + графік P(R) ┘
```

## [A] Електричний опір (с. 111–112)
- $R = 1/k$ — величина, обернена до провідності (англ. resistance). 1 Ом: при 1 В тече 1 А.
- Звідки береться (метали): електрони **розсіюються** на дефектах ґратки та її **теплових коливаннях**.
- Не залежить від I (при помірних струмах); залежить від геометрії, матеріалу та стану (T, p).

## [B] Опір провідника (с. 112–113)
- $R = \rho\dfrac{l}{S}$ (2.18), де ρ — **питомий опір** (англ. resistivity), Ом·м.
- $\sigma = 1/\rho$ (2.21) — **питома електропровідність** (англ. conductivity), См/м.
- Найменший ρ: срібло, мідь, золото, алюміній (з них роблять дроти). Великий ρ: ніхром (нагрівачі), константан і нікелін (еталонні резистори).
- Поділ за σ: провідники σ > 10⁶, діелектрики σ < 10⁻¹⁰, напівпровідники — проміжні значення (См/м); звірено зі сканом.

## [C] Температурна залежність (с. 112–113)
- **Температурний коефіцієнт опору** (англ. temperature coefficient of resistance) $\alpha = \dfrac1\rho\dfrac{d\rho}{dT}$ (2.19). Метали: α > 0. Електроліти: α < 0.
- Для металів поблизу 0 °C $\alpha\approx 1/273$ К⁻¹ і $\rho = \rho_0(1+\alpha t)$, або $\rho = \rho_0\alpha T$ (2.20).
- Застосування: термометри опору, термостати, болометри.

## [D] Робота струму (с. 121)
- $A = IUt$ (2.38) $= I^2Rt = \dfrac{U^2}{R}t$ (2.39)
- Повна робота джерела по всьому колу: $A_{заг} = \mathcal E It$ (2.41).

## [E] Потужність (с. 121–123)
- **Потужність** (англ. power) — робота за одиницю часу.
- **Корисна** (англ. useful power; у навантаженні R): $P = IU = I^2R = \dfrac{U^2}{R}$ (2.43) $= \dfrac{\mathcal E^2R}{(R+r)^2}$ (2.44)
- **Загальна** (англ. total power): $P_{дж} = \mathcal EI = \dfrac{\mathcal E^2}{R+r}$ (2.45)
- **ККД** (англ. efficiency): $\eta = \dfrac{P}{P_{дж}} = \dfrac{R}{R+r}$ (2.46)
- Максимальна корисна потужність при **R = r**: $P_{max} = \dfrac{\mathcal E^2}{4r}$, але тоді η = 50 %.
- ✏️ Графік P(R): нуль при R = 0, максимум при R = r, прямує до 0 при R → ∞. Поверх — η(R), що зростає до 1.
