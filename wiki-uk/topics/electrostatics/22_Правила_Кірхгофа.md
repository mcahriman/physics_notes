# 22. Перший та другий закон Кірхгофа — каркас

📖 т. 2, **§ 2.6** «Електричне коло. Правила Кірхгофа» (с. 126–131). ✅ Формули звірено зі сканом.
У книзі — **правила** Кірхгофа, у програмі — «закон». Вживаються обидва.

## План сторінки
```
┌ [A] Прості з'єднання: послідовне / паралельне (табличка)    ┐
├ [B] Терміни: розгалужене коло, вузол, ділянка, контур        ┤
├ [C] I правило (2.54) + рис. 2.12 │ [D] II правило (2.55) + рис. 2.13 ┤
└ [E] Як складати рівняння: знаки, незалежні контури           ┘
```

## [A] Послідовне і паралельне з'єднання опорів (с. 127–128)
| | послідовне (рис. 2.7) | паралельне (рис. 2.9) |
|---|---|---|
| струм | I = I₁ = I₂ = … | I = I₁ + I₂ + … |
| напруга | U = U₁ + U₂ + … | U = U₁ = U₂ = … |
| опір | R = R₁ + R₂ + … | 1/R = 1/R₁ + 1/R₂ + … |
| пропорція | U₁/U₂ = R₁/R₂ | I₁/I₂ = R₂/R₁ |
- **Дільник напруги (потенціометр)** (англ. voltage divider), с. 127.
- Необов'язково, батареї джерел (с. 128–129): послідовно ℰ = Σℰₖ, r = Σrₖ; n однакових паралельно дають r = r₁/n.

## [B] Терміни (с. 129)
- **Розгалужене коло** (англ. branched circuit): мережа з кількох контурів зі спільними ділянками.
- **Вузол** (англ. node): «Точку розгалуженого кола, в якій сходяться **три або більше** провідників із струмами»
- **Ділянка** (англ. branch): частина контуру між двома вузлами, по якій тече один струм.

## [C] Перше правило (с. 129)
- Виражає **закон збереження заряду** у вузлі: «алгебрична сума сил струмів, які сходяться у вузлі, дорівнює нулеві» (англ. Kirchhoff's current law)
- $\sum_{k=1}^n I_k = 0$ (2.54). Струми, що входять у вузол, — зі знаком +, що виходять, — зі знаком −.
- Чому справджується: інакше у вузлі накопичувався б заряд, змінювалися б потенціали, і струм не був би постійним.

## [D] Друге правило (с. 130)
- Узагальнення **закону Ома** на контур: «у контурі алгебрична сума спадів напруг (добутків сил струмів на опори відповідних ділянок) дорівнює алгебричній сумі електрорушійних сил, які діють у цьому контурі» (англ. Kirchhoff's voltage law)
- $\sum_{k=1}^n I_kR_k = \sum_{k=1}^m \mathcal E_k$ (2.55)
- Ідея доведення: записати (2.33) для кожної ділянки контуру й додати; **потенціали скорочуються**.

## [E] Як користуватися (с. 129–131)
1. Напрям кожного струму обирають довільно; від'ємна відповідь означає, що струм тече навпаки.
2. Обирають напрям обходу кожного контуру. IR береться з +, якщо струм збігається з напрямом обходу. ℰ береться з +, якщо при обході джерело проходять від − до +.
3. Беруть лише **незалежні** контури — ті, які не можна утворити з інших.
- ✏️ Розв'яжіть самі один приклад за рис. 2.13: три ділянки, два вузли.
