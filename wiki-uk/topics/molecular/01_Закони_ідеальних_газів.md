# 1. Закони ідеальних газів — каркас

📖 т. 1, **§ 14.6** «Рівняння стану ідеального газу» (с. 311–313), **§ 14.7** «Основні закони ідеального газу» (с. 313–317). ✅ (14.13)–(14.18) звірено зі сканом; (14.22)–(14.31) — з чіткого OCR.
Блок A, сторінка 2 з 3. Підхід книги: **дослідні** закони виводяться **як наслідки** p = n₀kT.

## План сторінки
```
┌ [A] Рівняння стану: pV = nkT → Клапейрон → Клапейрон–Менделєєв ┐
├ [B] Таблиця трьох ізопроцесів (закон, рівняння, графік)         ┤
│     + три маленькі графіки p–V, V–T, p–T (рис. 14.5–14.7)       │
├ [C] Закон Авогадро                                               ┤
└ [D] Межі застосування моделі                                    ┘
```

## [A] Рівняння стану ідеального газу (с. 311–313)
- **Термічне рівняння стану** (англ. thermal equation of state): рівняння, що пов'язує p, V, T у стані теплової рівноваги, $F(p, V, T) = 0$ (14.12).
- З МКТ: $p = n_0kT$ (14.13) ⟹ $pV = nkT$ (14.14), де n — кількість молекул.
- Для одного моля: $pV_M = N_AkT$ (14.15). З **молярною газовою сталою** (англ. molar gas constant) $R = kN_A = 8{,}31$ Дж/(моль·К):
  $pV_M = RT$ (14.16) — **рівняння Клапейрона**.
- Для довільної кількості речовини, ν = m/M молів:
  $$pV = \frac mM RT,\quad\text{або}\quad pV = \frac{n}{N_A}RT\qquad(14.18)$$
  — **рівняння Клапейрона–Менделєєва** (англ. ideal gas law).
- Зміст R (с. 313): робота розширення 1 моля ідеального газу при **ізобарному** нагріванні на 1 К. ✏️ Намалюйте поршень із рис. 14.4.

## [B] Ізопроцеси (m = const) (с. 313–316)
| процес | умова | закон (назва в книзі) | рівняння | графік |
|---|---|---|---|---|
| **ізотермічний** | T = const | закон **Бойля–Маріотта** | pV = const (14.22) | p–V: гіперболи (рис. 14.5) |
| **ізобарний** | p = const | закон **Гей-Люссака** | V/T = const (14.25); V = V₀(1 + αt) (14.26) | V–T: прямі через початок координат (рис. 14.6) |
| **ізохорний** | V = const | «рівняння ізохорного процесу» | p/T = const (14.28); p = p₀(1 + βt) (14.29) | p–T: прямі через початок координат (рис. 14.7) |

- α = β = 0,003661 К⁻¹ ≈ 1/273 — **коефіцієнт об'ємного розширення** і **термічний коефіцієнт тиску**.
- Необов'язково: ізотермічний коефіцієнт стисливості $\chi = -\dfrac1V\left(\dfrac{\partial V}{\partial p}\right)_T = \dfrac1p$ (14.24) і зв'язок $\beta = \alpha/(p\chi)$ (14.31).
- У підручнику ізохорний закон **не названо законом Шарля**. Якщо лектор так його називає, допишіть самі (англ. Charles's law).
- ✏️ Намалюйте три маленькі графіки з кількома кривими (T₁ < T₂, p₁ < p₂, V₁ < V₂) і позначте, яка крива відповідає більшому параметру.
- Тут лише закони. Робота, теплота і ΔU для кожного процесу — у блоці E ([07–09](07-09_Ізопроцеси.md)).

## [C] Закон Авогадро (с. 316)
- З pV = nkT: «в однакових об'ємах ідеальних газів при однакових температурах і тисках міститься однакове число молекул» (англ. Avogadro's law)

## [D] Межі застосування (с. 313)
- Модель справджується, коли власним об'ємом молекул і їхньою взаємодією можна знехтувати: **низький тиск і досить висока температура**. Нормальні атмосферні умови здебільшого підходять. Далі — [26, реальний газ](26_Реальний_газ.md).

## Необов'язково (приклад 14.1, с. 316)
- Вивести pV/T = const лише з дослідних законів: ізотерма 1→1′, потім ізохора 1′→2. Гарний прийом для іспиту, займає пів сторінки.
