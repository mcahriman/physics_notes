# 4. Теплота, робота, теплоємність — каркас

📖 т. 1, **§ 16.2**, частини «Макроскопічна робота», «Кількість теплоти» (с. 377–381). ✅ (16.5)–(16.9) звірено зі сканом.
Блок D, сторінка 2 з 4. Головна думка: **Q і A — функції процесу**; U — функція стану (тема 3).

## План сторінки
```
┌ [A] Робота: поршень (рис. 16.1), d'A = p dV (16.5), A = ∫p dV (16.6)     ┐
├ [B] Робота = площа під кривою; два шляхи A→B (рис. 16.2) → різна A       ┤
├ [C] Кількість теплоти: теплообмін, «мікроскопічна робота»; знаки          ┤
├ [D] Таблиця: робота vs теплота (макро/мікро; обидві — функції процесу)    ┤
└ [E] Теплоємність: C₀ = d'Q/dT (16.7), питома c (16.8), молярна C = Mc (16.9) ┘
```

## [A] Макроскопічна робота (с. 377–378)
- Газ під поршнем площею S квазістатично розширюється на dx: $d'A = F\,dx = pS\,dx = p\,dV$ (16.5) (англ. work)
- **Знак** (угода книги): робота **газу** при розширенні **додатна**; робота зовнішніх сил над газом — від'ємна.
- $A = \int_{V_1}^{V_2}p\,dV$ (16.6)
- Означення книги (с. 378): «робота в термодинаміці — це **макроскопічна міра зміни внутрішньої енергії** системи у квазістатичних процесах»

## [B] Функція процесу (с. 378–379)
- На діаграмі p–V **A = площа під кривою** процесу (рис. 16.2).
- Два різні шляхи A→B мають різні площі, тобто різну роботу. Робота — **функція процесу, а не функція стану** (англ. path function).
- Звідси позначення **d'A, а не dA**: це не повний диференціал.
- У циклі робота може бути ≠ 0 — на цьому й працюють теплові машини.
- ✏️ Головний малюнок: два шляхи AmB і AnB, площі під ними заштриховано по-різному.

## [C] Кількість теплоти (с. 380)
- **Теплообмін** (англ. heat transfer): «Процес передачі енергії від більш нагрітого тіла до менш нагрітого **без виконання макроскопічної роботи**». Його міра — **кількість теплоти Q** (англ. heat).
- Механізм — зіткнення молекул; іноді це називають «мікроскопічною роботою».
- Знаки: теплота, **надана** системі, — +, відібрана — −. Одиниця: Дж.
- Q теж функція процесу, тому пишуть **d'Q**.

## [D] Робота vs теплота (с. 380)
| | робота A | теплота Q |
|---|---|---|
| форма передачі енергії | **макрофізична**: енергія впорядкованого руху | **мікрофізична**: сукупність молекулярних процесів |
| пов'язана зі зміною | зовнішніх параметрів (V) | жодних; лише теплообмін |
| функція | процесу (d'A) | процесу (d'Q) |
| спільне | обидві — міри **передачі енергії**, у Дж | |

## [E] Теплоємність (с. 380–381)
- $C_0 = \dfrac{d'Q}{dT}$ (16.7) — теплота, потрібна для нагрівання на 1 К (англ. heat capacity).
- **Питома теплоємність** (англ. specific heat capacity) c — на одиницю маси: $C_0 = mc$ (16.8)
- **Молярна теплоємність** (англ. molar heat capacity) C — на моль: $C = Mc$ (16.9)
- Позначення: C_p (ізобарна), C_V (ізохорна), C_T (ізотермічна), C_ад (адіабатна). Оскільки d'Q залежить від процесу, **теплоємність теж залежить від процесу**. Значення для ідеального газу — на [05](05_Теплоємність_ідеальних_газів.md).

## Доповнення (не з книги)
Наші скорочення й виведення. У книзі таких записів немає.
- **Знак роботи: дві домовленості** (→ [A]): ця книга (як і більшість фізичних та інженерних текстів) вважає A роботою, виконаною **системою**, тож $d'Q = dU + d'A$. У хімії та за IUPAC W — робота, виконана **над** системою, і $\Delta U = Q + W$. Фізика та сама, знак доданка з роботою протилежний. Перш ніж переписати формулу з іншого джерела, перевірте, яку домовленість воно вживає.
- **d′ чи δ** (→ [B]): книга позначає неповний диференціал штрихом: d′Q, d′A. В інших текстах — δQ, δA або đQ. Усе це одне: мала кількість, яка не є зміною функції стану.
