# 5. Теплоємність ідеальних газів — каркас

📖 т. 1, **§ 16.2** (рівняння Майєра, с. 382–383), **§ 16.5** «Теплоємність ідеального газу» (с. 390–397). ✅ (16.16)–(16.19), (16.46) і таблицю C_V/C_p звірено зі сканом.
Блок D, сторінка 4 з 4. Саму таблицю C_V подано на [20–21](20-21_Ступені_вільності_внутрішня_енергія_ідеального_газу.md). Тут — **C_V vs C_p**, **γ** і **де класична теорія не працює**.

## План сторінки
```
┌ [A] C_V = dU/dT; C_p — більше; рівняння Майєра (16.19) у рамці        ┐
├ [B] Класична теорія: C_V = (i/2)R, C_p = ((i+2)/2)R, γ = (i+2)/i — таблиця ┤
├ [C] Графік C_V(T) для двохатомного газу (рис. 16.7): сходинки 3/2 → 5/2 → 7/2 ┤
└ [D] Чому: квантування; характеристичні температури T_оберт, T_колив      ┘
```

## [A] Рівняння Майєра (с. 382–383) — у рамку
- З першого закону для одного моля, $d'Q = C_VdT + p\,dV$ (16.17):
  - V = const: dV = 0, тож $C_V = \left(\dfrac{\partial U}{\partial T}\right)_V$ (16.16)
  - p = const: p dV = R dT, тож $d'Q = C_VdT + R\,dT$ (16.18)
  $$C_p = C_V + R\qquad(16.19)$$
  — **рівняння Майєра** (англ. Mayer's relation).
- Зміст: при сталому p частина теплоти йде на **роботу розширення**, а не лише на U. Тому C_p > C_V, і саме на R (зміст R — на [01](01_Закони_ідеальних_газів.md)).

## [B] Класична теорія (с. 390–392)
- З U = (i/2)RT: $C_V = \dfrac i2R$, $C_p = \dfrac{i+2}2R$, $\gamma = \dfrac{C_p}{C_V} = \dfrac{i+2}i$
| газ | i | C_V | C_p | γ |
|---|---|---|---|---|
| одноатомний | 3 | 3/2 R | 5/2 R | 5/3 ≈ 1,67 |
| двохатомний (жорсткий) | 5 | 5/2 R | 7/2 R | 7/5 = 1,4 |
| багатоатомний (жорсткий) | 6 | 3R | 4R | 4/3 ≈ 1,33 |
- γ — **показник адіабати** (англ. adiabatic index), знадобиться в темі 10.
- Загальна формула з коливаннями: $U = (3 + r + 2s)\dfrac{RT}2$ (16.46).

## [C] Невдачі класичної теорії (с. 392–394)
1. Складні молекули: для C₂H₅OH жорстка модель дає 3R, пружна — 24R, а дослід — близько 8R. **Обидві моделі не працюють.**
2. **Залежність від температури** не пояснюється. Для двохатомного газу, рис. 16.7:
   - низькі T: C_V ≈ 3/2 R, ніби є лише поступальний рух (H₂ нижче 60 К поводиться як одноатомний);
   - кімнатні T: 5/2 R («увімкнулося» обертання);
   - тисячі К: прямує до 7/2 R (вмикаються коливання, але молекули раніше дисоціюють).
- ✏️ Намалюйте «сходинки» C_V(T) з переходами при T_оберт і T_колив.

## [D] Квантове пояснення (с. 394–397), коротко
- Енергії обертання й коливань **квантуються**: $\varepsilon_{пост} \ll \varepsilon_{оберт} \ll \varepsilon_{колив}$, звідси **характеристичні температури** (англ. characteristic temperatures) $T_{пост} \ll T_{оберт} \ll T_{колив}$.
- Нижче T_оберт чи T_колив енергії kT замало, щоб збудити відповідний рух, тож ці ступені вільності «заморожені».
- Значення: T_оберт для H₂ — 85 К, для N₂ — 2,85 К; T_колив для N₂ — 3340 К, для O₂ — 2240 К.
