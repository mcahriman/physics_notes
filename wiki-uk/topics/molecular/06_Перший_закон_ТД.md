# 6. Перший закон термодинаміки — каркас

📖 т. 1, **§ 16.2** «Перший закон термодинаміки» (с. 374, 381–383). ✅ (16.10)–(16.17) звірено зі сканом.
Блок D, сторінка 3 з 4. Поєднує теми 3 і 4: два способи змінити U.

## План сторінки
```
┌ [A] Звідки: механічна енергія не зберігається при терті → теплота = енергія ┐
├ [B] Формулювання + (16.10) dU = d'Q − d'A  ⚠️ знаки!                        ┤
├ [C] Зручна форма (16.11) d'Q = dU + d'A; інтегральна (16.12); цикл (16.13)  ┤
├ [D] Вічний двигун I роду неможливий                                         ┤
└ [E] Для ідеального газу: d'Q = C_V dT + p dV (16.17) → місток до 05, 07–10   ┘
```

## [A] Звідки закон (с. 374)
- Механічна енергія зберігається лише без **дисипативних сил**. При терті вона «зникає», але з'являється теплота. Урахування внутрішньої енергії теплового руху відновлює закон збереження.
- «Перший закон термодинаміки — це **узагальнений закон збереження й перетворення енергії** для тих макроскопічних систем, для яких суттєву роль відіграє тепловий рух» (англ. first law of thermodynamics)

## [B] Формулювання (с. 381) — у рамку
- «у теплових процесах зміна внутрішньої енергії відбувається за рахунок приросту кількості теплоти і виконаної роботи»
  $$dU = d'Q - d'A\qquad(16.10)$$
- ⚠️ **Неточність у книзі.** Під (16.10) сказано «d'A — робота, виконана **над** системою», але зі знаком мінус і власною угодою книги на с. 378 (d'A = p dV > 0 при розширенні) d'A має бути роботою, виконаною **самою** системою. Запишіть: **d'A — робота системи проти зовнішніх сил.** Адіабатний випадок (16.20), d'A = −dU («система виконує роботу внаслідок зменшення внутрішньої енергії»), підтверджує це прочитання.

## [C] Інші форми (с. 382)
- Форма через теплоту, зручна для теплотехніки: $d'Q = dU + d'A$ (16.11). Словами: надана теплота **йде на** збільшення U і виконання роботи.
- Інтегральна форма: $Q = (U_2 - U_1) + A$ (16.12)
- Цикл (U₂ = U₁): $Q = A$ (16.13) — уся отримана теплота перетворюється на роботу.
- Якщо d'Q = 0, процес **адіабатний** (тема 10).

## [D] Вічний двигун першого роду (с. 382)
- «неможливо побудувати машину, що діє періодично, яка виконувала б роботу без одержання енергії ззовні або виконувала б більшу роботу, ніж одержана ззовні енергія» (англ. perpetual motion machine of the first kind)

## [E] Ідеальний газ (с. 382–383)
- U = U(T, V) (16.14), але для ідеального газу (∂U/∂V)_T = 0, тож $dU = C_VdT$ (16.16), де $C_V = (\partial U/\partial T)_V$.
- Один моль:
  $$d'Q = C_VdT + p\,dV\qquad(16.17)$$
  Із цього рядка випливає все в блоках D–E: рівняння Майєра ([05](05_Теплоємність_ідеальних_газів.md)), ізопроцеси ([07–09](07-09_Ізопроцеси.md)) і адіабата ([10](10_Адіабатний_процес.md)).
