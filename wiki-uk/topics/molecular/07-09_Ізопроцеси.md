# 7. Ізотермічний процес · 8. Ізохоричний процес · 9. Ізобарний процес — каркас

📖 т. 1, **§ 16.4** «Робота ідеального газу при ізопроцесах. Політропний процес» (с. 386–390); самі закони — у **§ 14.7** (с. 313–316, див. [01](01_Закони_ідеальних_газів.md)). ✅ (16.26)–(16.33) звірено зі сканом.
Блок E, сторінка 1 з 2. Правопис: у програмі «ізохоричний», у книзі — «**ізохорний**».
Користуйтеся разом із підсумковою [таблицею процесів](../../concepts/isoprocesses-table.md) — найкориснішою окремою сторінкою для МКР.

## План сторінки (по блоку на процес, у кожному ті самі 5 рядків)
```
┌ [Ізохорний V = const]  ┬ [Ізобарний p = const] ┬ [Ізотермічний T = const] ┐
│ закон: p/T = const     │ V/T = const (Г-Л)     │ pV = const (Б-М)          │
│ графік p–V: вертикаль  │ горизонталь + площа   │ гіпербола + площа         │
│ A = 0                  │ A = p(V₂−V₁)=νRΔT     │ A = νRT ln(V₂/V₁)          │
│ ΔU = νC_VΔT            │ ΔU = νC_VΔT           │ ΔU = 0                     │
│ Q = ΔU                 │ Q = νC_pΔT            │ Q = A                      │
└────────────────────────┴───────────────────────┴────────────────────────────┘
          + низ: політропний процес pVⁿ = const об'єднує всі (16.40)
```
(ν = m/M)

## Ізохорний процес, V = const (с. 386–387)
- Приклад: нагрівання газу в жорсткій герметичній посудині (англ. isochoric process).
- $d'A_V = p\,dV = 0$, $A_V = 0$ (16.26)
- З першого закону: $d'Q = dU = \dfrac mMC_VdT$ (16.27) і $\Delta U = \dfrac mMC_V(T_2 - T_1)$ (16.28).
- **Уся теплота йде на внутрішню енергію.**

## Ізобарний процес, p = const (с. 387)
- Приклад: газ під вільно рухомим поршнем або нагрівання води у відкритій посудині (англ. isobaric process).
- $A_p = p(V_2 - V_1) = \dfrac mMR(T_2 - T_1)$ (16.29). На діаграмі p–V це **прямокутник** (рис. 16.4).
- $Q_p = \dfrac mM(C_V + R)(T_2 - T_1) = \dfrac mMC_p(T_2 - T_1)$ (16.30)
- Теплота йде **і на ΔU, і на роботу** (Майєр).

## Ізотермічний процес, T = const (с. 387–388)
- Потрібен ідеальний тепловий контакт із **термостатом** (тілом сталої температури) і дуже повільний перебіг (англ. isothermal process). Усі фазові переходи першого роду (наприклад, кипіння) ізотермічні.
- dU = 0, тож $d'Q = d'A$ (16.31): **уся теплота перетворюється на роботу**.
- $$A_T = \frac mMRT\ln\frac{V_2}{V_1}\qquad(16.32)$$
- Також: $Q_T = A_T = \dfrac mMRT\ln\dfrac{p_1}{p_2} = p_1V_1\ln\dfrac{V_2}{V_1}$ (16.33)
- ✏️ Площа під гіперболою. Пам'ятайте, звідки логарифм: ∫dV/V.

## Низ: політропний процес (с. 388–389), необов'язково, але красиво
- Процес зі **сталою теплоємністю C** (англ. polytropic process): $pV^n = \text{const}$ (16.40), де $n = \dfrac{C_p - C}{C_V - C}$ (16.37).
| процес | C | n |
|---|---|---|
| ізобарний | C_p | 0 |
| ізотермічний | ∞ | 1 |
| адіабатний | 0 | γ |
| ізохорний | C_V | ±∞ |
- Усі чотири процеси — окремі випадки одного рівняння.

## Самоперевірка
1. У якому процесі вся теплота йде на роботу, а в якому — вся на U?
2. Чому C_T = ∞? (Теплоту надають, а ΔT = 0.)
3. Намалюйте всі три процеси на одній діаграмі p–V з однієї початкової точки.
