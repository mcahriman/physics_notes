# 10. Адіабатичний процес — каркас

📖 т. 1, **§ 16.3** «Адіабатний процес. Рівняння Пуассона» (с. 383–386). ✅ (16.20)–(16.25) звірено зі сканом.
Блок E, сторінка 2 з 2. Термінологія: у програмі «адіабатичний», у книзі — «**адіабатний**». Пишіть за книгою.

## План сторінки
```
┌ [A] Означення + умови (теплоізоляція, «достатня повільність»)        ┐
├ [B] Перший закон: dU + d'A = 0 (16.20) → pdV = −C_V dT (16.21)        ┤
├ [C] Виведення → рівняння Пуассона TV^(γ−1) = const, pV^γ = const      ┤
├ [D] ГРАФІК: адіабата крутіша за ізотерму (рис. 16.3) + чому           ┤
└ [E] Робота (16.24)–(16.25); приклади з життя                          ┘
```

## [A] Означення (с. 383–384)
- **Адіабатний процес** (англ. adiabatic process): «що відбувається **без теплообміну** з навколишнім середовищем» (d'Q = 0).
- Дві умови: **теплоізоляція** (нетеплопровідні стінки) і **достатня повільність**, щоб процес лишався квазістатичним. На практиці процес роблять швидким, щоб теплота не встигала піти, але повільнішим за швидкість звуку.

## [B] Перший закон (с. 384)
- $dU + d'A = 0$ (16.20) ⟹ $d'A = -dU$. «система виконує роботу внаслідок **зменшення внутрішньої енергії**»
- Один моль: $p\,dV = -C_VdT$ (16.21). **Розширення охолоджує** газ, стискання — нагріває.

## [C] Рівняння Пуассона (с. 384) — у рамку
- Підставляємо p = RT/V: $\dfrac{dT}T = -\dfrac R{C_V}\dfrac{dV}V$ (16.22). Інтегруємо, врахувавши R/C_V = γ − 1:
  $$TV^{\gamma-1} = \text{const}\ (16.23),\qquad pV^\gamma = \text{const},\quad pT^{\frac\gamma{1-\gamma}} = \text{const}\ (16.23a)$$
- **γ = C_p/C_V** — **показник адіабати**, або **коефіцієнт Пуассона** (англ. adiabatic index; значення — на [05](05_Теплоємність_ідеальних_газів.md)).

## [D] Адіабата vs ізотерма (с. 384–385)
- Ізотерма: p ∝ 1/V. Адіабата: p ∝ 1/V^γ, γ > 1, отже **адіабата крутіша**.
- Фізично: при адіабатному розширенні p спадає і тому, що **V зростає, і тому, що T спадає**.
- ✏️ Головний малюнок, рис. 16.3: ізотерма й адіабата через одну точку, адіабата крутіша, заштрихована площа роботи V₁→V₂.

## [E] Робота (с. 385)
- $A = -\dfrac mMC_V\int_{T_1}^{T_2}dT = \dfrac mMC_V(T_1 - T_2)$ (16.24)
- $$A = \frac mM\frac{RT_1}{\gamma - 1}\left[1 - \left(\frac{V_1}{V_2}\right)^{\gamma-1}\right]\qquad(16.25)$$
- Приклади з життя:
  - повітря, що піднімається в тропосфері, адіабатно розширюється й охолоджується — тому вгорі холодніше;
  - двигуни внутрішнього згоряння;
  - одержання низьких температур.

## Самоперевірка
1. Чому газ охолоджується при адіабатному розширенні, хоча теплоту не відбирають?
2. Чому адіабата крутіша за ізотерму? Дві причини одним реченням.
3. Повітря: γ = 1,4. Як зміниться T, якщо об'єм зменшити вдвічі? (×2^0,4 ≈ 1,32.)
