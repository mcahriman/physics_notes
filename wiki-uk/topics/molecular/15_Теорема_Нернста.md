# 15. Теорема Нернста — каркас

📖 т. 1, **§ 16.11** «Третій закон термодинаміки. Недосяжність абсолютного нуля температур» (с. 414–415). У книзі це **третій закон**; «теорема Нернста» — його історична назва. ✅ (16.93) і наслідки звірено зі сканом (с. 414–415).
Блок F, сторінка 5 з 5. Коротка тема: пів сторінки.

## План сторінки
```
┌ [A] Навіщо: ентропія відома лише до сталої (16.76) → потрібен новий постулат ┐
├ [B] Формулювання Нернста (1906) — рамка                                     ┤
├ [C] Формулювання Планка: lim S = 0 при T → 0 (16.93)                        ┤
└ [D] Наслідки: недосяжність 0 К · C_p, C_V → 0 · коефіцієнти розширення → 0  ┘
```

## [A] Навіщо (с. 414)
- Перший і другий закони дають лише **зміни** ентропії; S₀ у (16.76) лишається невизначеною. Цього досить, доки не змінюється **хімічний склад** — це проблема хімічної спорідненості.
- Тож потрібен був **новий постулат**, що узагальнює нові досліди при низьких температурах.

## [B] Формулювання Нернста (1906) (с. 414–415)
- «при наближенні температури до абсолютного нуля ентропія будь-якої рівноважної системи при ізотермічних процесах **перестає залежати від термодинамічних параметрів стану** і при T → 0 набуває **ту саму для всіх систем сталу величину**, яку можна вважати такою, що дорівнює нулю» (англ. Nernst heat theorem)
- Нернст розглядав лише **конденсовані** системи — тверді тіла й рідини.

## [C] Формулювання Планка (с. 415)
- Планк пішов далі: сама ентропія прямує до нуля, для **будь-якої** системи:
  $$\lim_{T\to0}S = 0\qquad(16.93)$$
  — найзагальніше формулювання третього закону (англ. third law of thermodynamics).

## [D] Наслідки (с. 415)
1. **Абсолютний нуль недосяжний.** Усі методи охолодження використовують адіабатні процеси. Поблизу 0 К різниця між адіабатним та ізотермічним процесами зникає, тож охолодження стає дедалі менш ефективним. До 0 К можна наближатися лише асимптотично. Закон іноді формулюють як «принцип недосяжності абсолютного нуля».
2. $C_p, C_V \to 0$ при T → 0. Це підтверджено дослідом і квантовими теоріями Ейнштейна та Дебая; порівняйте з [05](05_Теплоємність_ідеальних_газів.md), де класична теорія не справляється.
3. Термічні коефіцієнти розширення й тиску → 0.

## Три закони разом (добре підходить для низу сторінки)
| закон | суть |
|---|---|
| I | енергія зберігається: Q = ΔU + A |
| II | напрям: S ізольованої системи не зменшується |
| III | S → 0 при T → 0; 0 К недосяжний |
