# 16. Другий закон термодинаміки — каркас

📖 т. 1, **§ 16.8** «Другий закон термодинаміки. Теорема Карно. Поняття про ентропію. Характеристичні функції» (с. 403–409). ✅ (16.69)–(16.74) звірено зі сканом.
Блок F, сторінка 3 з 5. Сама ентропія (той самий параграф, від с. 406) — на [14](14_Ентропія.md).

## План сторінки
```
┌ [A] Що визначає закон: НАПРЯМ процесів + межу перетворення Q → A      ┐
├ [B] Три формулювання: Клаузіус · Томсон · Оствальд (у рамках)          ┤
├ [C] Теорема Карно: два твердження; η ≤ η₀ (16.69)                     ┤
├ [D] Кількісно: нерівність Клаузіуса Q₁/T₁ + Q₂/T₂ ≤ 0 (16.71); зведена теплота ┤
└ [E] Узагальнення на довільний цикл ∮d'Q/T ≤ 0 (16.74) + рис. 16.13     ┘
```

## [A] Що визначає (с. 403)
- Перший закон дозволяє будь-який процес, що зберігає енергію. **Другий закон** (англ. second law of thermodynamics) «визначає **напрям** термодинамічних процесів та встановлює максимально можливі границі перетворення теплоти в роботу». Це узагальнення досвіду.

## [B] Формулювання (с. 403–404)
- **Клаузіус (1850)**: «теплота не може **сама собою** переходити від менш нагрітого тіла до більш нагрітого»
- **Томсон (Кельвін, 1851)**: «не можна побудувати машину, що діє періодично, яка б неперервно перетворювала теплоту в роботу **тільки внаслідок охолодження одного тіла**, без того, щоб у навколишніх тілах не відбулося одночасно певних залишкових змін»
- **Оствальд**: «**вічний двигун другого роду** неможливий» (англ. perpetual motion machine of the second kind). Така машина працювала б, охолоджуючи океан; закону збереження енергії вона не порушує, але її забороняє другий закон.
- ✏️ Порівняйте з вічним двигуном **першого** роду ([06](06_Перший_закон_ТД.md)), який заборонено законом збереження енергії.

## [C] Теорема Карно (с. 404)
1. ККД **оборотного** циклу Карно не залежить від робочого тіла й конструкції; він дорівнює ККД циклу з ідеальним газом при тих самих температурах (англ. Carnot's theorem).
2. ККД **необоротного** циклу завжди менший.
- $\eta \le \eta_0$ (16.69): рівність — для оборотного циклу, < — для необоротного.

## [D] Нерівність Клаузіуса (с. 404)
- Підставляємо $\eta = \dfrac{Q_1 - |Q_2|}{Q_1}$ і $\eta_0 = \dfrac{T_1 - T_2}{T_1}$ (16.70). При Q₂ < 0:
  $$\frac{Q_1}{T_1} + \frac{Q_2}{T_2} \le 0\qquad(16.71)$$
  (англ. Clausius inequality)
- **Зведена теплота** (англ. reduced heat) — теплота, якою система обмінюється з резервуаром, поділена на абсолютну температуру цього резервуара.
- Словами: сума зведених теплот в оборотному циклі Карно дорівнює 0, у необоротному — менша за 0.

## [E] Довільний цикл (с. 405)
- Будь-який оборотний цикл можна розбити сіткою ізотерм і адіабат на елементарні цикли Карно (рис. 16.13); внутрішні ділянки взаємно знищуються.
- $$\oint\frac{d'Q}T = 0\ \text{(оборотний)}\ (16.73),\qquad \oint\frac{d'Q}T \le 0\ \text{(загалом)}\ (16.74)$$
- (16.74) — другий закон для довільного циклу. Оскільки (16.73) дорівнює 0, d'Q/T має бути диференціалом **функції стану** — це **ентропія**. Продовження — на [14](14_Ентропія.md).
- ✏️ Намалюйте рис. 16.13: овал, розбитий сіткою ізотерм і адіабат.
