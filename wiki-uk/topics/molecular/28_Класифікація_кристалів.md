# 28. Класифікація кристалів — каркас

📖 т. 1, **§ 18.1** «Кристалічні та аморфні тіла. Основні характеристики кристалів» (с. 444–450); класифікація за типом зв'язку — **§ 18.2** «Сили зв'язку у твердих тілах» (с. 450–453). ✅ Звірено зі сканом (с. 446–448).
Блок H, сторінка 1 з 3. Книга класифікує кристали **двома способами**: за **симетрією** (сингонії, гратки Браве) і за **типом зв'язку**. Розгляньте обидва.

## План сторінки
```
┌ [A] Тверде тіло: кристалічне vs аморфне (дальній/ближній порядок, анізотропія) ┐
├ [B] Моно- і полікристали; закони кристалографії; елементи симетрії          ┤
├ [C] Гратка, вузли, елементарна комірка, rₙ = ma₁ + na₂ + pa₃ (18.1)          ┤
├ [D] ТАБЛИЦЯ 7 сингоній + 4 типи граток Браве (14 разом) + малюнки кубічних   ┤
└ [E] Класифікація за типом зв'язку: іонні · ковалентні · металічні · молекулярні ┘
```

## [A] Кристалічні та аморфні тіла (с. 444–445)
- **Тверде тіло** (англ. solid): «агрегатний стан речовини, який характеризується стабільністю форми та об'єму», а також упорядкованим розміщенням атомів, що здійснюють малі коливання біля положень рівноваги.
| | кристалічні | аморфні |
|---|---|---|
| порядок | **дальній** (англ. long-range): строга періодична повторюваність у 3D | лише **ближній** (англ. short-range) |
| властивості | **анізотропія** (англ. anisotropy): властивості залежать від напряму | **ізотропні** (англ. isotropic) |
| приклади | метали, сіль, кварц | скло, бурштин, смола, полімери |
- **Монокристал** (англ. single crystal; один великий правильний кристал) vs **полікристал** (англ. polycrystal; багато дрібних зерен, хаотично зрощених; більшість металів).

## [B] Закони кристалографії і симетрія (с. 445–446)
- Плоскі грані й прямі ребра; **сталість кутів між гранями**; раціональні відношення відрізків на осях.
- **Закон симетрії**: можливі лише осі порядку **1, 2, 3, 4 і 6** (осі 5-го порядку немає).
- Елементи симетрії: **вісь симетрії** (англ. symmetry axis; поворот на 2π/n), **площина симетрії** P (англ. mirror plane; дзеркальна) і **центр інверсії** C (англ. centre of inversion).

## [C] Просторова гратка (с. 446–447)
- Поставивши точку в центр мас кожної структурної одиниці, отримують **просторові гратки** (англ. space lattice); їхні точки — **вузли** (англ. nodes).
- **Елементарна комірка** (англ. unit cell): паралелепіпед на векторах a₁, a₂, a₃; їхні довжини — **періоди ідентичності** (англ. lattice periods). Будь-який вузол: $\vec r_n = m\vec a_1 + n\vec a_2 + p\vec a_3$ (18.1).
- **Гратки Браве** (англ. Bravais lattices): комірки мінімальної площі, що зберігають повну симетрію. Їх **14** у **7 сингоніях** (англ. crystal systems).

## [D] 7 сингоній (с. 447–449, табл. 18.4)
| сингонія | ребра | кути | приклади (з книги) |
|---|---|---|---|
| триклінна | a ≠ b ≠ c | α ≠ β ≠ γ ≠ 90° | польові шпати |
| моноклінна | a ≠ b ≠ c | α = γ = 90° ≠ β | гіпс, слюда, тальк |
| ромбічна | a ≠ b ≠ c | α = β = γ = 90° | сірка, топаз |
| ромбоедрична (тригональна) | a = b = c | α = β = γ ≠ 90° | кальцит, телур |
| тетрагональна | a = b ≠ c | α = β = γ = 90° | рутил, олов'яний камінь |
| гексагональна | a = b ≠ c | α = β = 90°, γ = 120° | лід, графіт, цинк |
| кубічна | a = b = c | α = β = γ = 90° | більшість металів, алмаз |
- Типи граток: **примітивна** (англ. primitive; вузли у вершинах), **базоцентрована** (англ. base-centred), **об'ємноцентрована** (англ. body-centred: Fe-α, W, Na), **гранецентрована** (англ. face-centred: Al, Cu, Ag, Au).
- ✏️ Намалюйте три кубічні гратки: просту, об'ємноцентровану й гранецентровану.
- Необов'язково: **індекси Міллера** (h k l) для площин, с. 449; **230 просторових груп** (Федоров, 1890); **32 класи** симетрії.

## [E] За типом зв'язку (§ 18.2, с. 450–453)
| тип кристала | у вузлах | зв'язок | властивості | приклади |
|---|---|---|---|---|
| іонний | ± іони | електростатичний | міцний, висока T_пл, поганий провідник | NaCl |
| ковалентний (атомний) | нейтральні атоми | спільні електронні пари, **напрямлений, насичений** | дуже тверді, висока T_пл, діелектрики або напівпровідники | алмаз, Si |
| металічний | + іони | **електронний газ** | добрі електро- й теплопровідники, блиск, ковкість | Cu, Au |
| молекулярний | молекули | ван-дер-ваальсів, водневий | низька T_пл, ізолятори | органічні кристали, лід |
