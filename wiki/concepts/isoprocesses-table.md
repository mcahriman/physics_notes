# Процеси в ідеальному газі: одна таблиця

[index](../index.md) · topics: [01 закони](../topics/molecular/01_Закони_ідеальних_газів.md), [07–09](../topics/molecular/07-09_Ізопроцеси.md), [10](../topics/molecular/10_Адіабатний_процес.md), [05 C](../topics/molecular/05_Теплоємність_ідеальних_газів.md)

ν = m/M moles. The first law: Q = ΔU + A. For an ideal gas always **ΔU = νC_VΔT**. Sources: т. 1, § 14.7, § 16.3–16.4.

| процес | умова | рівняння | закон | A (газ) | ΔU | Q | C | n (pVⁿ) |
|---|---|---|---|---|---|---|---|---|
| ізохорний | V = const | p/T = const | (14.28) | 0 | νC_VΔT | = ΔU | C_V | ±∞ |
| ізобарний | p = const | V/T = const | Гей-Люссака | p(V₂−V₁) = νRΔT | νC_VΔT | νC_pΔT | C_p = C_V + R | 0 |
| ізотермічний | T = const | pV = const | Бойля–Маріотта | νRT ln(V₂/V₁) | 0 | = A | ∞ | 1 |
| адіабатний | d'Q = 0 | pV^γ = const, TV^(γ−1) = const | Пуассона | νC_V(T₁−T₂) | −A | 0 | 0 | γ |
| політропний | C = const | pVⁿ = const | (16.40) | — | νC_VΔT | νCΔT | C | (C_p−C)/(C_V−C) |

✏️ One p–V diagram from a common point with all four curves: an isochore (vertical), an isobar (horizontal), an isotherm (hyperbola) and an adiabat (a steeper hyperbola).

Values: one-atom γ = 5/3, two-atom 7/5, many-atom 4/3 (see [05](../topics/molecular/05_Теплоємність_ідеальних_газів.md)).
