# Позначення, знаки й одиниці

[index](../index.md)

A reference for reading other sources next to Кучерук: lecture slides, English textbooks, problem books, aerospace literature. The same physics can look different because the letters, signs or units differ. The book column is checked against the scans; "other texts" means common modern or English usage.

## Книга vs інші тексти

| величина | Кучерук | інші тексти |
|---|---|---|
| неповний диференціал | d′Q, d′A | δQ, δW, đQ |
| скалярний добуток | $\vec p\vec E$ (без крапки) | $\vec p\cdot\vec E$ |
| векторний добуток | $[\vec p\cdot\vec E]$, (1.25) | $\vec p\times\vec E$ |
| ротор, дивергенція | rot, div | ∇ ×, ∇ ·; curl |
| середнє | ⟨v⟩ | $\bar v$ |
| найбільш імовірна / середня квадратична швидкість | $v_н$ / $v_{кв}$ | $v_p$ / $v_{rms}$ |
| число молекул / концентрація | n / n₀ | N / n |
| молярна маса | M | M, μ (older texts) |
| ентальпія / потенціал Гіббса / вільна енергія | I / Z / F | H / G / F or A |
| гравітаційна стала | γ | G |
| теплопровідність | λ | k, κ |
| тепловий потік | $j_q$ | q, $\vec q$ |
| характеристичні температури | $T_{оберт}$, $T_{кол}$ | θ_rot, θ_vib |
| об'ємноцентрована гратка | J | I |
| холодильний коефіцієнт / коефіцієнт перетворення | ε / φ | COP_R / COP_HP |
| ЕРС | ℰ | ℰ, emf |

## Знаки

| що | Кучерук | інше |
|---|---|---|
| робота в першому законі | A — робота **системи**: $d'Q = dU + d'A$ (16.11) | хімія, IUPAC: W — робота **над** системою, ΔU = Q + W |
| теплота | надана системі > 0 (с. 380) | the same almost everywhere |
| Q₂ у циклі | у η = 1 − Q₂/Q₁ модуль; у (16.71) зі знаком, Q₂ < 0 | many texts write $Q_C$ or $\lvert Q_2\rvert$ throughout |
| дипольний момент | від − до + (1.19) | some chemistry texts draw the arrow from + to − |
| напрям струму | рух **позитивних** зарядів (т. 2, с. 106) | the same; electrons move the other way |
| нормаль у потоці | зовнішня — додатна (с. 36) | the same |
| ЕРС у правилі Кірхгофа | > 0, якщо обхід проходить джерело від − до + | the same convention, but check each text |

## Як не заплутатися
- When you copy a formula from another source, check three things first: what each letter means, the sign of the work, and whether it is per mole, per kilogram or for the whole body ($C$, $c$, $C_0$ in (16.7)–(16.9)).
- The book writes decimals with a comma (8,31); English texts use a point (8.31).
- In handwritten notes, pick one symbol per quantity and write a one-line legend at the top of the page if you deviate from the book.
