# 16. З'єднання конденсаторів — каркас

[← 15_Конденсатори_ємність](15_Конденсатори_ємність.md) · [index](../../index.md) · [syllabus](../../syllabi/electrostatics.md) · [glossary](../../glossary.md) · [17_Енергія_зарядженого_провідника →](17_Енергія_зарядженого_провідника.md)

📖 т. 2, **§ 1.14** (с. 63–64). ✅ Formulas checked against the scan. A short topic: half a page.

## Layout (two columns)
```
┌ Паралельне (рис. 1.31)        │ Послідовне (рис. 1.32)          ┐
│ U однакова                    │ q однаковий (електростатична індукція) │
│ q = q₁ + q₂ + …               │ U = U₁ + U₂ + …                  │
│ C = C₁ + C₂ + … (1.71)        │ 1/C = 1/C₁ + 1/C₂ + … (1.72)     │
│ n однакових: C = nC₀          │ n однакових: C = C₀/n            │
└ footer: навіщо (батареї); імпульс nU (рис. 1.33)                 ┘
```

## Паралельне з'єднання (p. 63)
- The same voltage U on every capacitor; the charges add: $q = (C_1+C_2+\ldots+C_n)U$.
- $C = C_1 + C_2 + \ldots + C_n$ (1.71)

## Послідовне з'єднання (pp. 63–64)
- **Electrostatic induction** gives every capacitor the same charge q; the voltages add.
- $\dfrac1C = \dfrac1{C_1}+\dfrac1{C_2}+\ldots+\dfrac1{C_n}$ (1.72)
- C is always **smaller than the smallest** Cᵢ.

## Why connect them (p. 63)
- To get a needed capacitance at a needed voltage, in a **батарея конденсаторів** (capacitor bank). Series connection splits the voltage, so the bank can handle a higher one.
- Trick (p. 64, рис. 1.33): charge n capacitors in parallel to U, then switch them to series and you get nU. Used for high-voltage pulses.

## ✏️ Your own line
- Contrast with resistors ([topic 22](22_Правила_Кірхгофа.md)): capacitors in parallel **add up**, while resistors **add up in series**. Note why: C ∝ q/U and R ∝ U/I.
