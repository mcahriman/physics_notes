# 22. Перший та другий закон Кірхгофа — каркас

## [A] Послідовне і паралельне з'єднання опорів (pp. 127–128)
| | послідовне (рис. 2.7) | паралельне (рис. 2.9) |
|---|---|---|
| струм | I = I₁ = I₂ = … | I = I₁ + I₂ + … |
| напруга | U = U₁ + U₂ + … | U = U₁ = U₂ = … |
| опір | R = R₁ + R₂ + … | 1/R = 1/R₁ + 1/R₂ + … |
| пропорція | U₁/U₂ = R₁/R₂ | I₁/I₂ = R₂/R₁ |
- **Дільник напруги (потенціометр)** (voltage divider), p. 127.
- Optional, batteries of sources (pp. 128–129): in series ℰ = Σℰₖ, r = Σrₖ; n identical in parallel give r = r₁/n.

## [B] Терміни (p. 129)
- **Розгалужене коло** (branched circuit): a network of several loops with shared sections.
- **Вузол** (node): «Точку розгалуженого кола, в якій сходяться **три або більше** провідників із струмами»
- **Ділянка** (branch): the part of a loop between two nodes, carrying one current.

## [C] Перше правило (p. 129)
- It expresses **charge conservation** at a node: «алгебрична сума сил струмів, які сходяться у вузлі, дорівнює нулеві»
- $\sum_{k=1}^n I_k = 0$ (2.54). Incoming currents are +, outgoing are −.
- Why it holds: otherwise charge would pile up at the node and the potentials would change, so the current would not be steady.

## [D] Друге правило (p. 130)
- A generalization of **Ohm's law** for a loop: «у контурі алгебрична сума спадів напруг (добутків сил струмів на опори відповідних ділянок) дорівнює алгебричній сумі електрорушійних сил, які діють у цьому контурі»
- $\sum_{k=1}^n I_kR_k = \sum_{k=1}^m \mathcal E_k$ (2.55)
- Proof idea: write (2.33) for each section of the loop and add them; **the potentials cancel**.

## [E] Як користуватись (pp. 129–131)
1. Pick a direction for each current at random; a negative answer means it flows the other way.
2. Pick a direction to go round each loop. IR counts + if the current runs with that direction. ℰ counts + if going round takes you through the source from − to +.
3. Use only **independent** loops, ones that can't be built by combining others.
- ✏️ Do one worked example yourself on рис. 2.13: three branches, two nodes.

## Self-check
1. Which conservation law does each rule express? (Charge; energy, through Ohm's law.)
2. How many independent node equations are there for N nodes? (N − 1.)
