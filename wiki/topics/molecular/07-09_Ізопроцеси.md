## Layout (one block per process, the same 5 rows each time)
```
┌ [Ізохорний V = const]  ┬ [Ізобарний p = const] ┬ [Ізотермічний T = const] ┐
│ закон: p/T = const     │ V/T = const (Г-Л)     │ pV = const (Б-М)          │
│ графік p–V: вертикаль  │ горизонталь + площа   │ гіпербола + площа         │
│ A = 0                  │ A = p(V₂−V₁)=νRΔT     │ A = νRT ln(V₂/V₁)          │
│ ΔU = νC_VΔT            │ ΔU = νC_VΔT           │ ΔU = 0                     │
│ Q = ΔU                 │ Q = νC_pΔT            │ Q = A                      │
└────────────────────────┴───────────────────────┴────────────────────────────┘
          + footer: політропний процес pVⁿ = const об'єднує всі (16.40)
```
(ν = m/M)

## Ізохорний процес, V = const (pp. 386–387)
- Example: heating a gas in a rigid, sealed vessel.
- $d'A_V = p\,dV = 0$, $A_V = 0$ (16.26)
- From the first law, $d'Q = dU = \dfrac mMC_VdT$ (16.27) and $\Delta U = \dfrac mMC_V(T_2 - T_1)$ (16.28).
- **All the heat goes into internal energy.**

## Ізобарний процес, p = const (p. 387)
- Example: a gas under a freely moving piston, or water heated in an open vessel.
- $A_p = p(V_2 - V_1) = \dfrac mMR(T_2 - T_1)$ (16.29). On the p–V diagram this is a **rectangle** (рис. 16.4).
- $Q_p = \dfrac mM(C_V + R)(T_2 - T_1) = \dfrac mMC_p(T_2 - T_1)$ (16.30)
- The heat goes into **both ΔU and work** (Mayer).

## Ізотермічний процес, T = const (pp. 387–388)
- It needs ideal thermal contact with a **термостат** (a body at constant temperature) and must be very slow. All first-order phase transitions (boiling, for example) are isothermal.
- dU = 0, so $d'Q = d'A$ (16.31): **all the heat becomes work**.
- $$A_T = \frac mMRT\ln\frac{V_2}{V_1}\qquad(16.32)$$
- Also: $Q_T = A_T = \dfrac mMRT\ln\dfrac{p_1}{p_2} = p_1V_1\ln\dfrac{V_2}{V_1}$ (16.33)
- ✏️ The area under the hyperbola. Remember where the logarithm comes from: ∫dV/V.

## Footer: політропний процес (pp. 388–389), optional but elegant
- A process with **constant heat capacity C**: $pV^n = \text{const}$ (16.40), with $n = \dfrac{C_p - C}{C_V - C}$ (16.37).
| процес | C | n |
|---|---|---|
| ізобарний | C_p | 0 |
| ізотермічний | ∞ | 1 |
| адіабатний | 0 | γ |
| ізохорний | C_V | ±∞ |
- All four processes are special cases of one equation.
